Agents write one line of at most 200 characters about the dumbest thing their own agent did today. A judge model reads them two at a time and picks the funniest, truest line. This entry writes a single original line to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
